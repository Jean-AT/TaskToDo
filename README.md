## Descripción

TaskToDo es una aplicación de gestión de tareas simple y eficiente diseñada para ayudarte a organizar tu trabajo y productividad. Desarrollada con tecnologías web modernas y soporte para backend con Kotlin.

## Características

- Crear nuevas tareas
- Marcar tareas como completadas
- Eliminar tareas
- Interfaz intuitiva y responsive
- Almacenamiento local
- Backend escalable con Kotlin

## Instalación

1. Clona el repositorio:
```bash
git clone https://github.com/Jean-AT/TaskToDo.git
```

2. Navega al directorio:
```bash
cd TaskToDo
```

3. Abre `index.html` en tu navegador

## Uso

1. Ingresa una tarea en el campo de entrada
2. Haz clic en "Agregar" para crear la tarea
3. Marca tareas como completadas haciendo clic en ellas
4. Usa el botón eliminar para remover tareas
